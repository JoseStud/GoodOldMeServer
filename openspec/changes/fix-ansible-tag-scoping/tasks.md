# Tasks

Groups 1-3 are the three pushes to `main` from design.md (Migration Plan). Keep each group's files inside its push class: group 1 touches only `.github/`, `ci/` and `docs/`, group 2 only `ansible/`, and group 3 only `.github/` and `docs/`. A `docs/` file in group 2 would turn its ansible-only push into a full run with infra apply, so the docs that describe group 2's behaviour land in group 3.
